## 不改变的安全边界

- `expected_version`、活 claim 归属和候选哈希绑定仍严格校验。
- mutation 回执是那次写入的快照。重放旧 op 不等于读取当前状态，也不会将新状态与旧版本拼接。
- 无安装基线的旧 Skill 不会被自动覆盖；用户修改有安装基线时也不能被静默替换。
- MCP 保留 text 与 structuredContent 的兼容载荷，调用包装器只渲染其中一份。
- `quick` 不作为绕过已匹配项目生命周期限制的隐式后门。
- 大小写、长度和组合约束按字段定义，不从相邻字段猜测。
