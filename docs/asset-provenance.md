# Visual asset provenance

This file records the source and distribution status of first-party visual assets shipped by AyanamiTaskManager.

| Asset      | Purpose                                                 | Provenance                                                                         | Distribution                                  |
| ---------- | ------------------------------------------------------- | ---------------------------------------------------------------------------------- | --------------------------------------------- |
| `logo.png` | README, application and packaged documentation branding | Original project artwork created and supplied by the AyanamiTaskManager maintainer | Included under AGPL-3.0-only with the project |
| `logo.ico` | Windows executable and installer icon                   | Icon conversion of the same maintainer-supplied project artwork                    | Included under AGPL-3.0-only with the project |

Product screenshots generated by this repository's smoke or E2E tests depict ATM's own interface and synthetic fixture data. Before publishing a screenshot, maintainers must confirm that it contains no personal project names, local paths, bearer tokens, database identifiers or third-party copyrighted content.

The application renders Phosphor icons through the `@phosphor-icons/react` dependency. Those icons are not copied into this repository as first-party artwork and remain subject to their upstream license. Other dependencies likewise retain their own license terms.
