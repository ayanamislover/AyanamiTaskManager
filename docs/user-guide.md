# 用户指南

## 安装与首次启动

运行 `AyanamiTaskManager-Setup-1.0.10-win-x64.exe` 完成当前用户安装，或解压 portable ZIP 后运行 `AyanamiTaskManager.exe`。应用在本机启动内置服务，不需要云端账号。

正式数据默认位于 `%LOCALAPPDATA%\AyanamiTaskManager`。portable 包默认仍使用正式数据目录；如需完全隔离，启动前设置 `AYANAMI_TASK_DATA_DIR`。

源码开发时，Web 界面固定使用 `http://127.0.0.1:9999`。该端口只服务前端；daemon API 继续使用运行时发现文件声明的独立本机端口。

在“设置”中开启登录启动后，应用会在 Windows 登录后的 8–45 秒内随机延迟启动，避免与其他登录项同时抢占资源。点击窗口关闭按钮只会隐藏到托盘，后台服务与 Agent 接入继续运行；单击托盘图标恢复窗口，使用托盘菜单“完全退出”才会停止服务。

## 总览

总览显示活动项目、活动任务、阻塞、等待和在线 Agent。项目卡同时显示健康度、当前里程碑、目标日期、进度来源、最近活动和 Agent 数。顶部“需要处理”只展示事实源中的等待、阻塞、超期、过期领取、缺少项目更新和备份失败。

临时任务适合几分钟内完成的一次性工作。总览最多展示 5 项，可直接勾选完成；需要持续管理时在“临时任务”页晋升到正式项目。

## 创建与管理项目

项目向导分三步：

1. 名称、短代码、源码目录、说明和协作模式；
2. 当前目标与首个里程碑；
3. Agent 配置安装、复制和连接测试。

每个正式项目使用独立 SQLite 文件，源码目录只写入轻量 `.ayanami-task/project.json` 标识，并把该目录加入仓库本地 exclude。项目可附加或更新主源码路径；同一路径不能属于两个项目。

项目页顶部显示目标、里程碑、健康度、项目进度及来源、下一目标日期。管理摘要分为当前进行、阻塞与等待、Agent/领取、最近项目更新和 READY 下一步。

项目可先归档，再移入垃圾箱。移入垃圾箱前自动创建 `PRE_TRASH` 备份；垃圾箱项目可以在项目列表恢复。不要把归档当删除：归档用于停止活动，垃圾箱用于从常用视图移除。

## 任务视图

- 列表：状态、优先级、负责人、层级、计划日、阻塞/等待、进度和最近更新。
- 看板：待开始、进行中、受阻、验收与完成。
- 时间线：按项目事件序列展示可重放变化；事件会区分任务状态、进度、记录、Session 和 Git 上下文变化，不再把所有事件都显示成“项目摘要已更新”。
- 层级：按父子任务展示执行树。
- 记录：保存决策、约束、事实、风险、参考、经验和验证材料。

筛选支持状态、负责人、里程碑、截止日期、阻塞和进度来源。可把组合保存为项目视图；保存视图采用版本化更新。

任务抽屉提供开始、阻塞、等待、验收、完成、取消、重开和释放过期领取。详情包含说明、进度来源、验收标准、检查项、依赖和 WorkItem 工程变更。

Agent 页面按项目聚合在线与历史 Session。每个 Session 的 Git 区域显示 ATM 从 `cwd` 只读采集的 branch、HEAD、worktree 和 dirty 状态；采集失败会明确标记不可用，不会阻止任务执行。相同 branch/worktree 的多个在线 Session 只显示冲突警告。

Git 上下文在开工、有意义的进度/项目更新、验收/完成、Session 结束或用户手动刷新时更新；打开页面或普通查询不会因为轮询而改写 Session。

## 工程统计

项目页工程统计由本地 `git ls-files`、`git diff --numstat` 和文件扫描计算，显示 Source/Test LOC、文件数、依赖数、7/30 日净 LOC、最大文件和高 churn 文件。任务级显示文件修改/新建/删除、行增删/净值、Source/Test 新增行和新增依赖。

指标是事实展示，不是代码质量分数。7 日净变化超过软阈值时只提示确认拆分，不阻止任务完成。尚无首个 commit 的仓库使用 Git 空树作为 baseline，不会自动创建提交。

## 搜索与键盘

- `Ctrl+K`：打开全局搜索。
- `Ctrl+N`：在项目内新建任务；其他页面进入临时任务。
- `Esc`：关闭当前对话框、命令面板或任务抽屉。
- `Tab` / `Shift+Tab`：焦点限制在当前对话层；关闭后恢复到打开按钮。

## 项目更新

“发布项目更新”先按上次发布后的事实生成草稿，再由用户确认健康度和摘要。已完成、风险和下一步来自项目数据，不调用模型生成。发布结果进入项目时间线和总览摘要。

## 数据工具

项目页“数据工具”支持手动备份、恢复、`.aytproj`/JSON/CSV 导出，以及旧 `agenttask.md` 预览和应用。导入先显示目标、里程碑、任务、参考记录和警告；相同 SHA-256 重复导入不会再次写入。
